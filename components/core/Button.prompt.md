Rounded pill button used for actions, purchases and the evolve prompt; color communicates the action type (green=go/buy, purple=evolve, gray=locked).

```jsx
<Button variant="primary">Go</Button>
<Button variant="evolve" size="lg">EVOLVE to Wolf (12/1.20K DNA)</Button>
<Button variant="locked" disabled>🔒</Button>
```

Variants: primary, secondary, locked, evolve, danger. Sizes: sm, md, lg.
