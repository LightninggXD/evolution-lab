Circular icon shortcut used down the HUD rail (Inventory, Shop, Auto Attack, VIP) with an optional corner tag and countdown.

```jsx
<IconBadge icon="🎒" label="Inventory" />
<IconBadge icon="🐵" label="Shop" tag={{label:'FREE!',variant:'free'}} />
<IconBadge icon="🐘" label="Cocofanto Pet" tag={{label:'LIMITED TIME',variant:'limited'}} timer="13:15:37" />
```
